# mini-GPT

A from-scratch, educational implementation of a GPT-style (decoder-only Transformer) language model in Python, built incrementally to mirror the architecture described in the original GPT-2 paper.

## Project Goals

This project implements the core building blocks of a GPT model from the ground up — no high-level Transformer libraries — to build a clear understanding of how each component works and fits together.

## Status

🚧 Work in progress — architecture is implemented; training loop, checkpointing, and evaluation scripts still be in development.
